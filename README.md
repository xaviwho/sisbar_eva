# sisbar_eva — lineage-grounded evaluation of cell couplings and state representations

Code and result tables for an evaluation study that uses measured clonal lineage (SISBAR
split barcoding; You et al., *Cell Stem Cell* 2023, doi:10.1016/j.stem.2023.02.007) to test
two assumptions behind differentiation models:

1. that inferred couplings (entropic optimal transport, OT) link early cells to their true
   descendants, and
2. that marker-based cell states, such as (P, D), carry a cell's fate.

Every number, figure and table in the paper is generated by the scripts below from the
saved outputs in `results/`. No result is typed by hand.

`UPDATES.md` is the dated working log (decisions, runs, checks); `CLAUDE.md` holds the standing

Public GEO data only (about 3 GB):

| File | Content |
|---|---|
| `GSE207921_RAW.tar` | per-library 10x matrices, replicate 1, stages I–IV |
| `GSE221592_RAW.tar` | per-library 10x matrices, replicates 2–3, stages I–IV |
| `GSE221592_Virusbar_processed_data_combined.xlsx` | authors' cell-to-viral-barcode table with cluster labels |

```bash
python scripts/00_download_geo.py          # downloads to data/raw/ and checks SHA-256
python scripts/00_download_geo.py --check-only
```

The expected SHA-256 values are the ones recorded in `results/*/provenance.txt`. `data/` is
git-ignored. Intermediate files (`.h5ad` objects, cached OT potentials, per-seed caches) are
regenerated by the scripts and are never committed.

## Environment

- **Local steps** (`requirements.txt`): Python 3.11, pandas, numpy, scipy, openpyxl,
  matplotlib. These steps need no scanpy.
- **Linux steps** (`environment/requirements-cloud.txt`, a full `pip freeze`): Python 3.13,
  scanpy 1.12.5, anndata 0.13.4, POT 0.9.7.post1, scikit-learn 1.9.1, scikit-misc,
  torch 2.15.0 (CPU build). The original runs used a Linux workspace with 2 CPUs and a
  5.8 GB memory limit. Run one OT job at a time on a machine of that size.
  (`results/03_objects` was built with scanpy 1.11.4 and scipy 1.18.1; see its
  provenance file.)

Each script writes `results/NN_*/provenance.txt` with the git commit it ran from, package
versions and the SHA-256 of its inputs. Scripts were committed before they were run, so the
recorded commit is the code that produced the output.

superseded by steps 1–2 and not used for any result. The paper sources are in `paper/`.

## Protocol rules (summary)

- Splits are by clone, never by cell; sister cells never cross partitions.
- Normalisation, scaling and PCA for prediction tasks are fitted on training data only.
- One shared split per seed for every model and coupling; 20 seeds; paired bootstrap 95%
  CIs, Wilcoxon with Holm correction, Cohen's d_z; equivalence margin δ = 0.01 MAE fixed in
  advance; constant baselines (training median and mean) always reported.

## Relation to earlier work

The forecasting protocol, Proposition 1 and the OT positive controls come from the
author's benchmark study ("Benchmarking Single-Cell Marker-State Forecasting Under
Independent and Coupled Cell Pairings"; code: https://github.com/xaviwho/leakage-safe-benchmark).
